## 專案結構 (Project Structure)
```text
模塊化組件/
├── .github/
│   └── workflows/
│       └── ci.yml                         # GitHub Actions CI：後端測試、前端 lint/build、模組搬移 script、文件檢查、Compose config、Docker build

│   └── workflows/                         # Spring 多模組除錯與工作流規則

├── module/
│   ├── backend/
│   │   ├── app/                           # Spring Boot 啟動模組
│   │   ├── module-common/                 # 共用基礎、DTO、Security、Exception、Utils
│   │   ├── module-auth/                   # 認證授權
│   │   ├── module-organization/           # 組織、員工、門市與終端資料
│   │   ├── module-workflow/               # 審批流程引擎
│   │   ├── module-notification/           # 通知與 WebSocket 推播
│   │   ├── module-attendance/             # 打卡考勤、班表、地理圍欄、假日
│   │   ├── module-leave/                  # 請假管理、假別、配額、申請與審核
│   │   ├── module-system/                 # 系統設定、功能開關、資料字典、流水號；resources/module-catalog.tsv 為模組移植清冊單一來源
│   │   ├── module-audit/                  # 稽核日誌、AOP 行為記錄、CSV 匯出
│   │   ├── module-finance/                # 財務管理、傳票、發票、報銷、預算
│   │   ├── module-payroll/                # 薪資結構、計薪、稅率、保險與薪資紀錄
│   │   ├── module-project/                # 專案、任務、看板、甘特圖、里程碑與工時
│   │   ├── module-document/               # 文件資料夾、中繼資料、版本、分享與標籤
│   │   ├── module-report/                 # 報表定義、SQL 防護、儀表板、排程與跨模組統計
│   │   ├── module-crm/                    # 客戶、聯絡人、商機、報價、合約與互動紀錄
│   │   ├── module-inventory/              # 品項、倉庫、出入庫、調撥、盤點與低庫存警示
│   │   ├── module-meeting/                # 會議室、預約、會議、會議紀錄與決議追蹤
│   │   ├── module-announcement/           # 公告、排程發布、發布範圍、已讀與回條追蹤
│   │   └── pom.xml                        # Maven multi-module 父 POM
│   ├── docker/local/                      # 本地 Docker Compose 與映像配置
│   ├── env/                               # 環境變數範本與本地 env/local 範本
│   └── frontend-web/
│       ├── public/
│       └── src/
│           ├── features/                  # auth、organization、workflow、attendance、leave、system、audit、finance、payroll、project、document、report、crm、inventory、meeting、announcement 等前端功能
│           ├── shared/navigation/          # 前端模組導覽與 Feature Toggle helper
│           └── shared/                    # API、auth、components、hooks、i18n、store、types、utils
├── 企畫書.md
└── 開發與測試整合規劃書.md
```
